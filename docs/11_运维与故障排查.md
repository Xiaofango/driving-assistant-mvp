# 运维与故障排查(11)

演示环境的实测排障手册。以下问题均在 2026-10-28/29 的实机联调中遇到过并验证过恢复方法。

## 快速对照表

| 症状 | 原因 | 处置 |
| --- | --- | --- |
| 页面点了没反应/指令像"丢失" | 8765 端口被多个服务进程分绑(已修复:服务启动时占用即退出) | 杀掉全部 web_demo 进程重启一个(见下) |
| 启动报"CARLA 服务器处于同步模式" | 上次退出时世界留在 synchronous_mode 且无人 tick | 跑"恢复异步"脚本(见下) |
| 车速 ~0.2 km/h、道路/车道显示 —、TM 不动 | 演示车出生在不良点位(卡路缘) | 页面点"重置演示"换出生点 |
| 连接 CARLA 超时(8 s) | CARLA 刚启动还在初始化 | 等端口就绪后重跑;`start_demo.ps1` 已内置 90 s 等待 |
| `tel:2000` 完全无响应 | CARLA 服务端进程退出(长时间高负载偶发) | 重跑 `.\scripts\start_carla_low.ps1` |
| 场景注入总报"没有可用位置" | 世界里累积了被强杀进程留下的车辆/行人 | 跑"清空世界"脚本(见下)后重置演示 |
| 画面不更新但数值正常 | 摄像头帧过期(>2 s)会显示等待,数据流独立 | 等下一帧;持续如此则重启演示服务 |

## 标准处置脚本

**杀掉全部演示进程**(PowerShell,强杀不会触发 CARLA 清理,之后建议配合清空世界):

```powershell
Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
  Where-Object { $_.CommandLine -like '*web_demo*' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

**恢复异步模式**(CARLA 服务器冻结在同步模式时):

```python
# .\.venv\Scripts\python.exe 执行
import carla
client = carla.Client("127.0.0.1", 2000); client.set_timeout(8.0)
s = client.get_world().get_settings()
s.synchronous_mode = False; s.fixed_delta_seconds = None
client.get_world().apply_settings(s)
```

**清空世界残留 actor**(强杀进程后车辆/行人/传感器会留在世界里):

```python
import carla
client = carla.Client("127.0.0.1", 2000); client.set_timeout(10.0)
world = client.get_world()
for pattern in ("vehicle.*", "walker.pedestrian.*", "controller.ai.*", "sensor.*"):
    for actor in world.get_actors().filter(pattern):
        try: actor.destroy()
        except Exception: pass
```

## 机制说明(为什么会发生)

1. **端口双绑**:Python `http.server` 默认 `SO_REUSEADDR`,Windows 语义下允许两个进程绑同一端口并分流请求。现已在 `web_demo.py` 用 `allow_reuse_address = False` 根治——第二个实例会直接报"端口已被占用"退出。若手动起服务遇到该报错,说明已有一个实例在跑。
2. **强杀与清理**:`Ctrl+C` 正常退出会销毁自建 actor、停止录制、退出同步模式;`Stop-Process -Force` 跳过全部清理,所以要配合上面的清空脚本。
3. **同步模式**:切换同步(20 Hz 定步长)后由采集线程拥有 tick;若线程所在进程被杀,世界无人 tick 即冻结。演示默认异步,同步模式仅供确定性复现,日常演示不要开。
4. **出生点**:出生点按地图顺序尝试,个别点位贴近路缘会导致 TM 无法起步,重置演示即换点,不是代码缺陷。
5. **录制文件**:录制开启后文件持续增长(实测一段 5 分钟 ≈ 130 MB,不含传感器附加数据)。演示后建议清理 `tmp/recordings/`。
6. **回放**:CARLA 回放会停止并重载当前世界,与持续采集冲突,因此演示内只录制不回放;离线回放用 CARLA 自带工具。

## 演示前检查单

1. `Get-NetTCPConnection -LocalPort 2000,8765 -State Listen`——两个端口各恰好一个监听者;
2. 打开页面等徽标"数据与画面实时同步",FRAME 在跳;
3. 车速上来后再开始话术演示(约 10~30 秒);
4. 完整走场一遍 [09 演示脚本](09_子Agent演示脚本.md)。
