# DA MVP 接口与安全契约

版本：1.0，2026-10-26

## PC → DA 请求

```json
{
  "session_id": "sess_demo_001",
  "user_id": "user_001",
  "utterance": "跟车距离调远一点",
  "context": {"turn_count": 1, "last_intent": null},
  "timestamp": 1793000000
}
```

`session_id`、`user_id`、`utterance` 为必填非空字符串；`timestamp` 是 Unix 秒，历史样例中的 `1756200000` 不是 2026-10-26。DA 不从自然语言推断用户身份或执行授权。

## DA → PC 结果

```json
{
  "session_id": "sess_demo_001",
  "reply_text": "跟车距离已调至 3 级。",
  "action_result": "success",
  "action_detail": {"type": "preference_changed", "name": "follow_distance", "value": 3},
  "need_follow_up": false,
  "timestamp": 1793000001
}
```

`action_result` 取 `success`、`no_change`、`clarification`、`rejected`、`unavailable`。只有网关明确确认后才能返回 `success`。网关失败或超时不能使用成功措辞。`need_follow_up` 为真时，PC 应继续收集用户信息。

## 状态快照

```json
{
  "timestamp": 1793000000,
  "adas": {"noa_status": "active", "follow_distance_level": 2,
           "current_speed_kmh": 88.5, "speed_limit_kmh": 120},
  "navigation": {"current_route_id": "route_a", "routes": [
    {"id": "route_a", "eta_min": 18}, {"id": "route_b", "eta_min": 15}
  ]},
  "latest_event": null
}
```

这是 DA MVP 的最小业务视图，尚未映射为正式 COVESA VSS 路径。公共平台应提供字段映射、时间同步与状态新鲜度保证。写操作前要求快照不超过 5 秒；过期时拒止。

## 工具白名单和边界

| 工具 | 类型 | 前置条件 |
| --- | --- | --- |
| `query_driving_status` | 只读 | 快照可用 |
| `set_driving_preference` | 网关请求 | NOA active；仅 `follow_distance` 1–5；目标值在范围内 |
| `modify_navigation` | 网关请求 | 候选路线明确、ETA 已知、目标路线确实更快 |
| `explain_adas_event` | 只读 | 有事件；已知码使用预置说明，未知码保守转述 |

MVP 的自然语言入口仅覆盖上述示例及少量同义表达；“调一下那个”等歧义话术必须追问。跟车距离越界时拒绝并解释，不静默截断。变道、加减速、制动、NOA 开关等控制意图一律拒绝。DA 只提出受限业务请求，网关/ADAS 仍须独立验证和决定是否执行。

## 安全优先级

紧急告警优先返回，普通写请求不执行。处理告警时给出操作建议，不声称 DA 可接管车辆。模拟状态与真实车辆状态应由接入方在界面上明确区分。

## 待双方确认

MQTT topic、JSON Schema 版本、鉴权方式、网关请求/响应相关 ID、超时与重试策略、事件码表、VSS 映射、导航候选路线来源。这些协议细节在原始材料里尚未定稿，本 MVP 使用本地函数接口。
